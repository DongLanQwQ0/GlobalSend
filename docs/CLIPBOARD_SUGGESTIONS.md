# 剪贴板建议

剪贴板建议直接显示在待发送区域中，使用虚线方形卡片，标明内容类型和“点按添加”。点击后才成为正式待发送内容；未确认时不计入数量，点击设备发送也不会带上它。× 忽略当前建议。原来的剪贴板按钮与 Ctrl+V 继续可用。

Android 悬浮窗的暂存区也显示同样的未确认建议卡，位于末尾空白格之后，与媒体建议放在一起。点击加入暂存，不混入接收记录；加入前不计入数量、全部拖拽或发送批次。任一入口忽略或使用当前建议后，两处同步隐藏；导入期间如又复制了新内容，新版本仍保留为未确认建议。建议只记录格式和版本，文件导入继续使用现有后台导入器。

悬浮窗建议区按建议时间倒序混排图片、视频与剪贴板；重新检查同一版本不会把它变成新建议。媒体建议在卡片实际可见且未操作时累计8秒后清除；收起、滑出、滚动或操作时暂停，恢复后继续剩余时间，不从发现时刻计时。剪贴板建议保留至添加、忽略或被新复制替换。仅有剪贴板建议时，前方空白格也能正常左右滑动，不会误触窗口移动。

- Windows 在应用前台检查系统剪贴板版本和格式，支持文本、图片和文件。
- iPad/iPhone 在前台检查剪贴板版本及类型，点击时通过系统提供方导入文本、链接、图片或文件；系统可能在实际粘贴时要求允许。
- Android 在系统允许访问时更新建议。在 GlobalSend 前台，点开把手或切到暂存直接检查格式，不切换焦点；在其它应用中，悬浮窗短暂获得本窗焦点进行检查。点建议才导入内容，随后恢复原窗口焦点标记。拖动悬停不会触发这一步。不增加无障碍或其他权限。
- Web 在浏览器已授予剪贴板读取权限时，回到前台检查建议；未授权或不支持权限查询时，使用原来的剪贴板按钮或粘贴。浏览器没有统一的剪贴板版本号，建议按本次前台交互显示，不承诺像原生客户端一样识别每次复制。

Android 暂存建议不读取其它应用的页面，也不依赖后台持续读取剪贴板。系统未允许悬浮窗获得焦点时，可回到发送页使用剪贴板入口。

## 如何识别新复制的内容

Android 监听系统剪贴板变更，用剪贴板时间戳加递增序号作为版本；发送页进入前台立即检查，此后每两秒检查元数据，退到后台停止轮询。建议只记录版本与类型，不比较或保存文本正文。再次复制相同文字也可能产生新版本，作为一次新复制建议；添加或忽略当前版本后，两处共享处理记录，不反复提示这一版。
