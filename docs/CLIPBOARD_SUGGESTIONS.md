# 剪贴板建议

发送页的“待发送”标题旁会显示剪贴板图标和内容类型。点击加入待发送，× 忽略当前建议；不会直接发送。原来的剪贴板按钮与 Ctrl+V 继续可用。

Android 暂存坞在末尾空白格之后显示剪贴板建议，与媒体建议放在一起。点击加入暂存，不混入接收记录；加入前不计入全部拖拽。任一入口忽略或使用当前建议后，两处同步隐藏，剪贴板有新版本时再提示。建议只记录格式和版本，文件导入继续使用现有后台导入器。

- Windows 在应用前台检查系统剪贴板版本和格式，支持文本、图片和文件。
- iPad/iPhone 在前台检查剪贴板版本及类型，点击时通过系统提供方导入文本、链接、图片或文件；系统可能在实际粘贴时要求允许。
- Android 在系统允许访问时更新建议。用户点开把手或切到暂存时，悬浮窗短暂获得本窗焦点以检查格式；点建议才导入内容，随后恢复原窗口焦点标记。拖动悬停不会触发这一步。不增加无障碍或其他权限。
- Web 在浏览器已授予剪贴板读取权限时，回到前台检查建议；未授权或不支持权限查询时，使用原来的剪贴板按钮或粘贴。浏览器没有统一的剪贴板版本号，建议按本次前台交互显示，不承诺像原生客户端一样识别每次复制。

Android 暂存建议不读取其它应用的页面，也不依赖后台持续读取剪贴板。系统未允许悬浮窗获得焦点时，可回到发送页使用剪贴板入口。
