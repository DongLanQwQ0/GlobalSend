# 1.0.12 手动验收

Windows、手机和Web/中心均已交付1.0.12。Windows位置 `E:\Programs\GlobalSend\globalsend.exe`；Web为 https://123.207.180.163/globalsend/app/ 。先让需要互传的设备加入相同组密码。

1. **布局**：Windows默认950×650下，待发、设备、共享框均可见，只有列表内部滚动；手机发送/接收切页、设置、下拉与正文不贴边，不被键盘遮住操作。
2. **发送**：添加文本、剪贴板文字/图片/文件、文件夹；Windows窗口内Ctrl+V和任意位置拖入。单击设备立即发送并清队列；多选先选设备，再确认发送。
3. **接收**：分别发送单项和多项，强调页展示正确、批次两列、Esc关闭不删历史；关闭过程中又来新内容，新内容不能消失。
4. **拖出与菜单**：Windows手指/笔长按已保存文件、图片整张卡片，拖入资源管理器；尝试取消后再次拖出。正文拖动只选字。右键菜单、定位文件也要检查；手机整卡跨应用拖出一起检查。
5. **后台**：Windows缩到托盘、手机在其他应用或锁屏时连续收件及文本更新。应持续接收、尝试弹出；无法弹出时使用通知，文本有复制入口。
6. **共享与编辑**：两端共同编辑共享框，不弹收件、不通知、不抢前台；手机能正常弹键盘、输入中文。已发文本可编辑，收到文本只读且可复制；图片/HTML等文本文件可预览，网址可打开。
7. **文件库和删除**：图片缩略图、排序、整卡多选、全选、复制文本、批删、转发；删除发送引用不应删除外部原件。
8. **设置与发现**：设备改名、刷新及切回前台刷新、离线30秒保留；选择接收位置后直接写入该目录，默认保留一天，清理类别/大小/时长能保存并生效。清理会删除接收原件，请用专门测试文件。

**已知未完成项**：Android自动判断“桌面或桌面+一个小窗时全屏，否则小窗”尚未实现精确环境判断。当前是有界接收窗口加显式全屏入口，不应把该项当成已完成行为。

若Windows出现凭据恢复页，可先“重试原身份”；仍失败时按界面确认“重新入组”。旧记录与文件保留，用户自行决定身份恢复；本次部署没有代操作。
