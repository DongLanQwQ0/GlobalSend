# 物理贴边、标签对齐与接收媒体排除 · 1.0.74+97

## 修改

- Android 暂存坞的左右边界使用屏幕物理边界，不再减去横向系统栏/刘海安全区。原生悬浮窗口同时关闭系统 inset fitting 并允许覆盖侧边 cutout，避免坐标计算正确但又被系统向内推。上下仍避开系统栏；胶囊内色条居中、8 倍惯性摩擦和位置记忆保持不变。
- Windows 桌面标签栏与右内容面板使用相同的左右留白、窗格间距和 10:11 列宽。旧公式使用 56px，而实际留白与列间距共 64px，造成约 4.19px 的左侧越界。进度线改为覆盖绘制，不再预留 2px 空白隔开标签和面板。放大文字时标题可省略，避免挤出标题区域。
- Android 在完成收件并请求系统文件索引之前登记接收文件的真实路径。媒体发现以该来源记录排除收件，不按文件名或整个目录过滤。发送页和悬浮暂存坞共享同一个原生候选源，因此都不重复建议收件；已进入建议的记录也会被移除，文件本身及接收条目保留。登记持久保存，目录迁移后的发布入口同样生效。
