# 胶囊内居中色条与更强惯性阻尼 · 1.0.74+96

用户最终明确：当前胶囊的贴边位置是正确的，实色色条应居中于胶囊；上一版松手后的惯性阻尼仍太小。

## 修改

- 胶囊位置、大小、圆角、透明度和向内的触摸范围全部保持 build 93 的状态。
- 只把 4dp 色条居中放进 12dp 胶囊：右侧水平内缩为 10/4dp，左侧为 4/10dp；相对于胶囊左右留白各 4dp。垂直位置同样居中。不再把色条推到屏幕边缘，也不拿 18dp 触摸范围作视觉居中基准。
- `OverScroller` 惯性摩擦系数从默认的 3 倍提升至 8 倍，只作用于松手后的滑行；拖动时仍逐像素跟手。没有增加新的设置项。

## 证据

原生定向测试 3 项通过，确认左右胶囊仍贴边、色条横纵居中、两侧可见留白相等、位置记忆和拖动控件未替换；保留惯性、再次触摸立即停止、边界限制和一比一跟手。

同一原生测试条件下（1500 px/s 释放速度），默认滑行距离为 392px，上一版 3 倍摩擦为 174px，当前 8 倍为 84px；新版本也更早停止。这是测试环境对照，不是手机手感实测。

原生测试仅跳过与其无关的 Dart 编译任务，Java、Android 资源和 Robolectric 渲染正常执行；随后仍使用完整原生发布工作流编译客户端。
