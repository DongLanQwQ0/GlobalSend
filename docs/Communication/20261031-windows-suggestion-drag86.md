# Windows 建议卡原生拖放：1.0.69+86

## 已实现

- Windows 剪贴板推荐、图片建议支持鼠标直接拖动和触屏长按拖动，复用现有 OLE / 桌面触屏适配及本窗口投放区域。
- 未确认建议不创建占位待发送项；明确投放到待发送区域或目标设备时，由原生投放事件处理真实文本/文件。拖动本身不确认、不发送。
- 成功投放后移除对应建议，取消则保留。点按添加、忽略按钮、Android 原生长按入口保留。
- 原生拖动直接使用当前卡片的像素预览，包含圆角与主题色。修复图片建议的鼠标悬停/按下高亮为不透明色、盖住缩略图的问题；现在使用主题色半透明高亮。
- 剪贴板支持文本、多文件及位图。文件保留外部引用；位图按需生成应用自有快照，不加入发送队列。已接受的快照为异步读取保留到下一次拖动，未使用的旧快照和取消产生的快照被清理，待发送/历史仍引用的快照保留。
- 本轮未新增 Windows 图片发现来源或目录扫描；为建议卡及剪贴板图片补齐拖放，不改变建议发现逻辑。

## 验证

- 模型 3 项通过：文本与多文件导出不确认、位图缓存及已引用快照保留、空剪贴板/失败清理。`artifacts/tmp/windows-suggestions86/tests.log`。
- Windows 目标平台下实际控件测试通过：鼠标与触屏分别拖动剪贴板和图片，取消保留、成功移除、队列不变、原生预览包含图片像素。`widget-accepted.log`。
- Android 剪贴板长按、媒体建议队列和现有 Windows 卡片拖动预览回归分别通过，日志在同一任务目录。
- 已查看原生预览的 JPEG：`clipboard-preview.jpg`、`photo-preview.jpg`。图片缩略图在悬停和按下时保持可见，无额外横向留白。
- Windows 按用户先前要求未进行真实桌面触控/跨应用投放操作；实机投放由用户手动验收。
