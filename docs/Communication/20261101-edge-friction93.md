# 收起把手贴边与惯性阻尼 · 1.0.74+93

用户指出右侧收起把手没有真正贴边，并澄清要求增加的是松手后的惯性阻尼，不是手指拖动阻力。

## 原因与修改

- 92 版反转控制栏时，把收起把手的显色区域也镜像到内侧，造成主题色竖线距窗口外边缘仍有 10dp 透明间隔。窗口位置已贴边，可见图形却没有贴边。
- 收起把手的底色和主题色竖线现在都画到实际贴边侧，不再留外侧透明边距；左右镜像处理。18dp 向内延伸的触摸范围保持不变，展开后的内侧控制栏不改。
- `OverScroller` 摩擦系数设为系统默认的 3 倍，仅影响松手后的惯性滑行；按下立即停止、逐像素跟手和向内拉开不变。

## 验证

原生定向测试 4 项通过：左右显色像素到达贴边边界及位置恢复、双侧同时移动缩放动画、跟手与松手惯性/按下停止/边界限制、与系统默认同释放速度的阻尼对照。

对照验证同一释放速度下滑行距离小于默认的 65%，并且更早停止。实际拖动仍按 120px 手指位移移动 120px。

已检查原生测试实际渲染的压缩预览 `artifacts/tmp/edge-friction93/render/edge-comparison.jpg`。用户 PNG 原图保持不变，仅检查项目内压缩副本。日志及证据集中在 `artifacts/tmp/edge-friction93/`。
