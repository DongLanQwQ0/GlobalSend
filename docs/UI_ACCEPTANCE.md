# GlobalSend 当前版手动验收

Windows和手机均已更新并启动 **1.0.42+51**；手机通过USB覆盖安装，实际版本读回成功，主界面已连接。重点验收：左右连续收拢无第二段系统动画；右侧竖排操作、透明×、复制提示、边缘缩放、背景按下偏移移动；收到内容自动展开、卡片独立进出；位置/尺寸记忆、横竖屏位置恢复及系统预览不触发误移除。微信正常聊天窗口的新版图片插入仍待确认；独立接收器可读文件或系统分享面板都不能替代微信插入验收，也不以自动发送消息作为验收动作。

## 1.0.30 本机应用联动

- Chrona 首次连接应显示原生关联页；明确允许后才能读取本组设备或发送所选网页。设置 → 本机应用联动可撤销，撤销后列表和发送同时失效。
- 按目标平台能力选择设备；普通文字、链接及组内共享不得自动开浏览器。独立网页意图同一ID重试或重连不重复打开，120秒过期不补开。
- Windows 确认系统浏览器实际启动；Android 前台直接打开、后台通过独立通知点击打开，通知不可用应返回失败。状态“系统接受启动”不等于页面已加载，Chrona8765网页可达及其配对另验。

接口和分工见 [ABI v1](INTEGRATION_ABI_V1.md)。现有中心HTTP/WS与注入启动器检查不替代上述系统交互。

## 1.0.35 暂存坞先查

1. Android 设置 → 接收与暂存坞：单一开关打开/关闭；顶栏无关闭、收起、打开按钮。双击中间内容打开主应用，按钮不误触发；贴边收起，把手透明触控区比可见部分大1.5倍；坞外仍能操作背景应用。
2. 接收 / 暂存分开。拖入图片、视频、文件和文本，多批追加不覆盖，也不产生接收记录。长按单项或六点图标（当前标签全部）拖出。
3. 暂存项拖放成功后 3 秒移除；倒计时轻点坞内一次取消，不同时打开文件。失败、取消及回投暂存坞保留，原文件和接收记录不删。
4. 更换亮 / 暗 / 中性及紫等主题色，Android 原生拖影和坞同步变化。外观选择“跟随系统”后，切换系统明暗应即时响应；草稿保留。
5. Android 发送区“应用”可搜索并选择已安装应用。单 APK 直接发送；拆分包保持 base 和所有 split APK 的真实目录结构，不只发送 base、不压缩成 ZIP。
6. Windows / Web 拖影中心跟随指针；Windows 鼠标和触屏拖出再拖回、投到其它应用仍需物理验收。

详细行为和 Android 冷后台 URI 授权验收边界见 [暂存坞说明](TEMPORARY_SHELF.md)。

## 既有修复继续回归

1. **登录不被文件库阻断**：手机安装新版后，保留原数据启动；即使接收目录有已被外部删除的文件，仍能恢复原分组。缺失文件只移除引用，暂不可读的目录保留记录，文件库问题不冒充账号失效。不清缓存、不重建身份来绕过问题。
2. **长按只拖放**：接收、历史、文件库均通过明确的多选按钮进入多选，单击选择，长按不再进入或改变选择。已有多选时，拖动选中内容仍可批量拖出；返回先退出多选。
3. **发送选择已测通路径**：刷新设备后，长按设备查看源、目标和实际检测结果。小文件应复用成功路径，不逐个等待；内网优先，其次公网（包括已允许的蜂窝），最后中继。允许四个文件默认并发，但单个文件不同时启动多个互相覆盖的写入器。
4. **接收坞及时显示、删除立即反馈**：电脑主窗失焦后收文字及小文件，文件开始时应见进度；完成后直接看文本或图片。右键删除应立即移除对应卡片，不因保存较慢而留在坞中，也不在迟到回复后重现。先用小文件，不用大中继流量测吞吐。
5. **更新只提示本平台**：设置中可检查更新；有 Windows/Android 包才分别提示对应平台。没有新 IPA，不应向 iPad/iPhone 提示别的平台 Release。GitHub 网络超时应显示检查失败，不能显示“已是最新”。当前 1.0.28 公开检查复测超时，不能记为通过。

## 重点检查

- [ ] **手机空间**：底部依次为发送、接收、历史、文件，默认发送；旧顶部三标签不重复显示。文本、剪贴板、文件、媒体、应用保持一行，操作区至少 44 高。切页有短过渡，草稿保留，软键盘正常输入中文。
- [ ] **电脑空间**：950×650 默认窗口，左侧无需整体滚动；待发送区只占一行卡片高度。右侧接收、已发送、文件库标签归属清楚；点击待发空白打开文本输入。调整位置/大小后退出重开，首次出现就应在保存的位置，不能先显示默认位置再跳转。
- [ ] **卡片**：图片占主要面积，底带紧凑，菜单右上，发送者较淡。接收页、突出弹层和接收坞都按实际接收时间倒序；进度刷新不让旧卡跳到最前。
- [ ] **图片缩放**：在非中心位置滚轮或双指放大，焦点下的图像点应保持；放大后四角均能平移查看，不被错误边界截住。加减按钮绕当前视口中心缩放，缩小到 50% 状态正确；“适应窗口”恢复完整居中。
- [ ] **整体拖动**：只读正文不再选字，文字、标题、页脚和空白都可起拖；复制、关闭、菜单仍可单独点击。真正的编辑框保留光标、选字和输入法。Windows 拖出再拖回后能继续拖；触屏长按后移动应拖放、不弹右键菜单，物理鼠标右键保留菜单。Android 保持系统长按拖放与原生拖影，能投回待发送区。
- [ ] **收件与回退**：Windows 主窗有焦点时在主窗内强调，否则使用独立接收坞，不缩放主窗。连续、多项收件不叠出破损窗口；Esc 关闭当前展示或返回上层，不删除内容。图片/文件页双击可在外部打开。
- [ ] **Windows 接收坞**：按最新要求，整窗有一层半透明主题底色，内容半透明；顶部数量/展开/关闭不再有独立底色块。卡片横向滚动不被竖条或菜单裁掉。首次出现从右侧滑入，关闭有退出动画；已显示时只更新内容，新卡进入、旧卡平移，不重放整窗弹出。移动保持按下点相对窗口的位置，不把左上角跳到光标；内容拖出不误触窗口移动。
- [ ] **多选与粘贴**：接收、历史、文件库整卡选择，支持全选及批量删除；长按不切换选择。删除发送历史不动外部原件。Ctrl+V 和剪贴板按钮试文字、图片、文件；空剪贴板不报错。Windows 剪贴板历史选择后，应将实际内容加入待发，而不是只能再次按 Ctrl+V。
- [ ] **共享与发现**：共享编辑静默、可撤销/重做，同步不清历史。刷新设备重新上传本机地址并通知同组；启动、恢复、获焦点、切网后更新。地址去掉回环并按网卡/来源分组。离线设备保留 30 秒可尝试发送，超时移除。
- [ ] **路径与续传**：小文件自动优先局域网，其次公网，最后中继；检查实际路径与速度，不以“公布了 IPv6”代替连接成功。直连决策目标是一秒内尝试候选，已连接传输不受此时长限制。手动指定路径不擅自换路；重试保留半文件前缀。
- [ ] **真实文件夹**：用含嵌套文件、空目录和超过 32 个文件的样本发送，接收位置应出现目录树，而非 ZIP。已有同名根目录不覆盖；收到的目录可转发。旧接收端应提示升级，不静默改成压缩包。
- [ ] **本地文件**：更换接收目录时迁移已有接收文件，之后直接写入该处，不额外复制整份。默认保留一天，只清图片和文本且不大于 500 KB，其他类别不默认勾选。自选目录中的本应用接收文件也按规则删除，目录内其他文件不动。外部移除文件后卡片更新；换组或中心不清本地历史。重复发送已有文件应更新接收时间，不重新传整份；合并文本的编辑应同步到原目标设备。
- [ ] **主题和图标**：亮色、暗色、中性主题及主题色立即生效，主窗、接收坞、设置和菜单保持一致；不残留固定绿色底。图标完整、系统字体清晰，包内不带字体文件。
- [ ] **系统分享**：Android 文件管理器、图库的单项/多项分享加入待发送，不自动发出。iPad 分享扩展需签名保留匹配 AppGroup，不能把普通文件选择器当作分享扩展验收；见 [系统分享](MOBILE_SHARING.md)。

## 当前进度与待验收

手机布局/切页、正文整体拖动、Native 真目录传输和 Web 真实浏览器 OPFS 目录接收已有对应证据。1.0.28 选路 39 项通过，包含实际本地 TLS 反向接收；前向连接故意不响应时，反向路径约 26–180 毫秒完成。它不代表手机蜂窝或校园网所有路径已通过。

Windows 设置与顶层弹窗的 Esc 在完整应用根组件（含更新提示层）回归通过。之前实际桌面操作曾出现 Esc 无反应，仍需在可交互桌面确认原生键盘投递，不能仅凭组件结果结案。此前桌面输入返回拒绝访问，已停止输入；手机随后通过新地址恢复连接并更新，启动日志未见应用错误。**仍需验收 Windows 连续滚动/拖出、实体触屏、实际后台接收，以及新版 Android 的文件库、后台弹出和系统拖放。**

图片缩放已有 12 项 Flutter 手势/像素检查及 4 项既有回归证据；真机偏心缩放与四角裁切仍需实际操作，不把控件探测或软件渲染当作这条路径通过。

Android 当前使用独立小型 overlay，并非 vivo 原生自由窗口；未实现自动判断桌面后切全屏。具体行为和验收见 [接收展示与通知](RECEIVE_NOTIFICATIONS.md)。
